# Child Health 2050 · Compass

The published files of the **Child Health 2050 · Compass** dashboard, served by GitHub Pages at
<https://o-karlsson.github.io/childhealth2050-site/>.

*What can I learn from countries like mine that achieved better child health outcomes?* The site
answers that four ways: one country at a glance, one indicator across countries, a country against
statistically similar peers, and a country's path to 2050. Only **Future Trajectories** is built
and published; the other three are in progress.

Every file here is generated from a separate working repository, and each commit is one publish.
Changes made here directly are overwritten by the next one.

To view it locally, serve this folder with any static web server — for example
`python -m http.server 8000`, then open <http://localhost:8000>.
